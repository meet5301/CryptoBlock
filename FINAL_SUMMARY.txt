================================================================================
                          TROUBLESHOOTING
================================================================================

"Connection refused"
  → Start MongoDB: mongod

"Port 5000 in use"
  → Kill process or change port in app.py

"Module not found"
  → Install deps: pip install -r requirements.txt

"Charts not showing"
  → Clear cache, restart app, check console

"Prices not updating"
  → Check WebSocket, restart app

"App won't start"
  → Run test_startup.py to diagnose
