# CryptoBlock - Quick Feature Guide (हिंदी/Hinglish)

## ✅ सब कुछ काम कर रहा है!

### 1. **Wallet (पैसा) Management**

#### जब आप Buy करते हो:
```
आप: BUY 0.5 BTC @ $97,000
Wallet cash: $10,000 - $48,500 = $1,500 remaining
```

#### जब आप SELL करते हो with Profit:
```
आप: SELL 0.5 BTC @ $100,000
Wallet cash: $1,500 + $50,000 = $51,500
Profit: +$1,500 (green color) ↑
```

#### जब आप SELL करते हो with Loss:
```
आप: SELL 0.5 BTC @ $90,000
Wallet cash: $1,500 + $45,000 = $46,500
Loss: -$3,500 (red color) ↓
```

### 5. **Trading - Step by Step**

#### Home Page में Chart खोलो
1. Chart पर दोहरा क्लिक करो (Double click)
2. Trading panel खुल जाएगा

#### Buy करो:
```
1. Quantity enter करो: 0.5
2. Stop Loss enter करो: $95,000 (optional)
3. BUY बटन दबाओ

Result:
✓ Cash minus हो जाएगा
✓ Coins increase होंगी
✓ Notification आएगी
```

#### Sell करो:
```
1. Portfolio page जाओ
2. "Sell" बटन दबाओ

Result:
✓ Cash increase होगी (profit के साथ)
✓ Coins कम होंगी
✓ P&L calculate होगा
✓ Notification आएगी
```
